# Mother's Day App

A polished React application to celebrate Mother's Day, featuring a memory gallery, a virtual bouquet, and reasons why she's special.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   
pm install
2. Run the app:
   
pm run dev

## Deployment

This app is ready to be hosted on Vercel. Simply push the code to a GitHub repository and import it into Vercel.
